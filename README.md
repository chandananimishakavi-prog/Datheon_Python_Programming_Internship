## 🎯 Projects & Tasks

### Task 1: Hangman Word Guessing Game (Console)
- Developed an interactive word-guessing game using Python.
- Implemented string manipulation and conditional statements.
- Used loops and functions to manage game flow.
- Added user input validation and guessing attempts.

**Concepts:** Strings, Loops, Conditional Statements, Functions.

### Task 2: Stock Portfolio Performance Tracker
- Developed a Python application to track stock portfolio performance.
- Calculated portfolio valuation based on stock prices and quantities.
- Implemented CSV file handling to store performance records.
- Generated portfolio performance logs.

**Concepts:** Python, File Handling, CSV, Data Structures, Calculations.

### Task 3: Automated File Organizer & Cleanup Utility
- Created a utility to organize files automatically.
- Sorted files into folders based on their extensions.
- Used Python OS libraries to perform filesystem operations.
- Simplified directory management and cleanup.

**Concepts:** OS Module, File Handling, Directory Management, Automation.

### Task 4: Rule-Based Interactive Terminal Assistant / Chatbot
- Developed an interactive terminal-based chatbot.
- Implemented rule-based responses for different user queries.
- Added multi-intent recognition.
- Created a conversational interface for user interaction.

**Concepts:** Python, Functions, Conditional Logic, String Processing, Pattern Matching.
